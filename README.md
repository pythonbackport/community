### Discussions Categories

When creating a new post, select the most appropriate category for your topic. 
This helps maintainers and contributors locate compatibility issues, backport demands efficiently.
This repo follows the pythonbackport public development roadmap tracking PEP backporting, 
cross-version compatibility tasks. For tidy management, GitHub Issues are disabled. 
We set dedicated categories for module adaptation, bug troubleshooting, porting requirements, 
plus a General category for miscellaneous content. Extra categories can be added later; 
uncategorized threads will be moved to General. All participants must abide by the [CODE OF CONDUCT](CODE_OF_CONDUCT.md).

### Disclaimer
All forward-looking plans are subject to change based on Python official updates, 
compatibility risks and manpower. Roadmap content does not constitute binding commitments. 
The team reserves rights to adjust development plans anytime.
